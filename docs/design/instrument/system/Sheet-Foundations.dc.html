Type, space, shape, motion

The system uses one sans (the platform system font) and one mono, with no web fonts. Hierarchy comes from size and weight. Numbers, times, versions and IDs are set in mono with tabular figures.

Type scale

{{t.name}} {{t.sample}} {{t.spec}}
Families. Sans: system-ui → SF Pro on Apple, Roboto on Android. Mono: ui-monospace → SF Mono, Roboto Mono. Weights. 400 and 700, plus 600 for the current nav item, field labels and button text. Uppercase always gets tracking. Mono for readouts. Use it for stats, times, durations, versions, hashes, tokens and URLs. Never for sentences.

Motion: three things move

Breathe. Scale 1 → 1.4, opacity .85 → 1, 1400 ms ease-in-out, alternating. Ready and live only.
Level meter. 3 bars, 20 → 100%, 600 + 120·i ms, delay 80·i ms. While audio is captured.
Spinner. 12 px ring, 800 ms linear, always beside a word (“Saving”). Processing only.
Nothing else moves. Dialogs, toasts and swapped rows appear without a transition. A swapped row holds accent-tint for 2 s. With reduced motion, the dot rests at 1.2, the bars hold at 60% and the spinner stops; the words still say what is happening.

Glyphs and icons

{{g.c}}{{g.m}}
Drawn icons only where no glyph fits: 24 grid, 1.5 stroke, square caps, currentColor, sizes 16 / 20 / 24.
Emoji are used only as bottom-bar and mode icons on phone, Wear and Auto (🎙 💬 📋 ⚙️). Nav labels still carry the meaning, because emoji ignore tint.

Wordmark: typeset, never drawn

{{m.name}} Live Lab {{m.ch}}
Set it as text. The app's name in sans 700 with −0.01em tracking, coloured text. It is never teal, never italic, and never has a logo, icon or gradient. Name it plainly. Use the proper name in Title Case: 1–2 words, at most 18 characters. No “the”, no version. Sizes. Header 15 · mobile app bar 16 · sign-in and Home tiles 32 (display) · macOS menu-bar menus use the system menu font. Always in this order. Switcher ▦, the name, 8 px, then the channel badge. The badge is never dropped, not even on LIVE.
